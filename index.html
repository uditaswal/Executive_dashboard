    Workbook Overview

    Supported sheets: DATA, REJECTIONDATA, CONFIG, SUGGESTIONS, REROUTE, and APN_VOLUME. The workbook should follow the WU standard column structure so filters, KPI cards, charts, RCA tables, and registers stay aligned.

    Sheet-name casing and spacing are tolerated. Rejection aliases such as RejectionData, Rejection Data, PAYOUT_DATA, and PayoutData are also accepted.

    Common Mistakes

    • Mixing WU Issue and wu issue in the same column is fixed by normalization.
    • Month values such as Jan-26 or 01/2026 are normalized to Jan 2026.
    • Numeric priorities stored as text like P2 are fixed by normalization.
    • Split delivery service values that are not in the synonym map still need to be consistent in the source.
    • Duplicate sheet names with different casing use the first matching sheet.
