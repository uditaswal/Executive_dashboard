      Workbook Overview

      Supported sheets: DATA, REJECTIONDATA, CONFIG, SUGGESTIONS, REROUTE, and APN_VOLUME. Add a workbook from the data/ folder with Auto Load or upload it manually from the sidebar.

      Sheet-name casing and spacing are tolerated, including aliases such as RejectionData and PayoutData.

      Common Mistakes

      • Mixing WU Issue and wu issue in the same column is fixed by normalization.
      • Leaving month as Jan-26 or 01/2026 is fixed by normalization.
      • Numeric priorities stored as text like P2 are fixed by normalization.
      • Split delivery service values that are not in the synonym map still need to be consistent in the source.
      • Duplicate sheet names with different casing use the first matching sheet.
