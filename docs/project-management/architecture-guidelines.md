# Non-Negotiable Rules

- Never add new hardcoded chart functions
- All widgets must use renderWidget()
- Use datasets abstraction
- Use cache layer for rejections
- No direct DOM creation outside widget renderer
- No new feature bypassing config system
- Code should be able to run on github pages
- don't use ai emoiji's
- maintain a 3-line comment block explaining what that file does in every file.
